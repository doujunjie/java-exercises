# 第4章 循环结构

## 本章知识点

- `for (初始化; 条件; 更新)`：适合循环次数已知的场景，循环变量只在 for 语句和循环体内有效。
- `while (条件)`：先判断后执行，适合次数不固定、只知道结束条件的场景。
- `do-while`：先执行一次循环体再判断条件，至少执行一次，结尾的 `while (...)` 后面必须写分号。
- `break`：立即结束当前这一层循环；嵌套循环中只跳出最近的一层。
- `continue`：跳过本次循环剩余的语句，直接进入下一次循环。
- 嵌套循环：外层控制行、内层控制列，打印图形和乘法表时最常用。
- `System.out.print` 不换行，`System.out.println` 输出后换行，二者配合可以控制输出布局。
- 累加器 `sum` 要先初始化为 0，累乘器要初始化为 1。
- 素数判断只需试除到 `i * i <= n`，并且要单独处理 `n <= 1` 的情况。
- 易错点一：`while` 循环体内忘记更新循环变量，会造成死循环。
- 易错点二：`do-while` 至少执行一次，不能用来表达“条件不满足就一次也不执行”。
- 易错点三：`break` 只跳出内层循环，需要跳出多层时应改用方法返回或标志变量。

## 进阶挑战

1. 打印图形：只用一个外层循环和若干内层循环，打印由 `*` 组成的菱形，行数由变量控制，先打印上半部分再打印下半部分。
2. 找出 1~1000 内的所有“完数”：一个数等于它所有真因数之和（例如 6 = 1 + 2 + 3），提示用内层循环枚举因数并累加。

## 怎么运行

1. 在 IntelliJ IDEA 中打开本项目，进入 `src/ch04_loops` 目录。
2. 打开任意练习文件，点击 `main` 方法左侧的绿色三角，选择 Run 即可运行自检。
3. 参考答案在 `solutions/ch04_loops` 目录下的同名文件中，对照实现与中文注释理解思路。
4. 也可以在项目根目录执行 `javac -encoding UTF-8 -d out src/ch04_loops/*.java`，再执行 `java -cp out ch04_loops.Ex01Sum`。
